# Stage 2 — migrate to uv with a coding agent

Start from a clean copy or Git commit of stage 1. Give the coding agent `prompts/01-convert-to-uv.md`.

## Review before accepting

The agent should change environment metadata and commands—not rewrite the data loader, regressions, ranking, tests, or export boundary.

Expected additions:

- `pyproject.toml` for direct runtime and development dependencies;
- `.python-version` and `requires-python` for Python 3.11;
- generated `uv.lock` for the exact solved graph;
- uv-based VS Code tasks and documentation.

`requirements.txt` becomes unnecessary after the migration is verified.

## Verify independently

```powershell
uv sync --frozen
uv run --frozen python -m pytest -q
uv run --frozen python run_analysis.py --input data/data.csv --output outputs --predict-temperature 40
uv lock --check
```

No activation command is needed. Delete `.venv`, repeat the `uv run` command, and observe that uv selects the project environment.

Compare `model_ranking.csv` and `summary.json` with the saved stage-1 artifacts. Tiny floating-point differences may be platform-dependent, but model ordering and substantive results should be unchanged.

The complete reference implementation is in `stage-02-uv`.
